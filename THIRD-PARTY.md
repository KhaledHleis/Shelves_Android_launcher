The addon is vendored rather than pulled in as a submodule so a clone builds
with nothing else to fetch. To update it, replace the folder with a newer
release and keep its LICENSE file.

The UI sounds in `godot/sounds/` were generated for this project and carry the
same licence as the rest of the repository.
